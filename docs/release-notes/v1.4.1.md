## Highlights
- Fix: version 1.4 did not open on some devices after the update. 1.4.1 starts again
- Favorites: sort your channels, movies and series by hand
- Xtream: backup server addresses, the app switches by itself when the main server is down
- Player: search subtitles online (OpenSubtitles, SubDL)

1.4.1 contains everything from 1.4. If you skipped 1.4 or it did not start for you, this is the full list.

## New
- Favorites: menu key or hold OK on an entry, then Move up / Move down / Move to top. The order is part of the backup and used for zapping
- Categories in Live TV, movies and series: sort by provider order, A-Z or your own order
- Xtream: any number of backup server addresses per login. Settings > Playlists shows which server is down and since when
- Player: search subtitles online under Audio & subtitles; the chosen subtitle is remembered per title. Needs your own API keys (Settings > API keys)
- Settings: new page "Alles zurücksetzen" resets all settings at once. Playlists, favorites, history, resume positions, API keys and the PIN are kept
- First start: "Weiter ohne Playlist" opens a demo mode with sample content to explore the app
- First start: a small card checks for app updates once and closes by itself when a playlist is added

## Improved
- App update: the download is checked (checksum, version, signature) before the installer opens, with a clear message instead of "App not installed"
- Stalker portals: movies and series load on demand, and movies and episodes play on more portals
- Xtream: the loading screen counts movies and series while they download
- Remote: a long OK now reacts after 0.35 s
- Live TV, home and sport tab: smoother scrolling and focus (not measured)
- TV guide search shows the show running right now with its times
- Backup now also includes dual view, new-episode marks, imported lists and the resume log
- Playlist refresh: "daily" is the new default; installs that still used "at every start" switch to "daily" once

## Fixed
- 1.4 did not open after the update on some devices. The build change behind it was undone
- The reset button on each settings page now resets only that page, not all settings
- Switching the content mode in Settings > Playlists no longer jumps back to the first settings page
- A playback error box no longer covers the TV guide in the player
- Search: the query box can be selected; Back goes to the input, then to the sidebar

## Good to know
- Install over 1.3 or 1.4; playlists, favorites, history and settings are kept (same signature).
- Empty Live TV or movie pages point to Settings > Playlists when the content mode hides them.
